# Security Policy

## Supported versions

This project is under active development and does not currently publish stable
release branches. Security fixes are applied to the latest code on the default
branch.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue or discussion.
When private vulnerability reporting is enabled, report them through GitHub's
security advisory form:

https://github.com/mkmyhre/matrix.tui/security/advisories/new

If that form is unavailable, contact the maintainer through the contact details
on the [maintainer's GitHub profile](https://github.com/mkmyhre) before sharing
details publicly.

Include reproduction steps, affected commands, expected impact, and any known
mitigation. Please allow time to investigate before publishing details.

This project is mainly AI-generated and has not been presented as independently
security audited. Use extra care when evaluating authentication, token storage,
and end-to-end encryption behavior.
